# 架构说明

## 分层

```
┌───────────────────────────────────────────┐
│ ui/      MainWindow / SettingsDialog /    │   只做界面与交互
│          CaptureOverlay                   │
├───────────────────────────────────────────┤
│ core/    App（业务总控）                   │   跨平台业务逻辑
│          Config / Log / Keys / ImageMatch │
│          Task → MouseTask / TargetTask    │
│          Recorder / Player / Hotkeys      │
├───────────────────────────────────────────┤
│ platform/ Platform.h（纯虚接口 + 工厂）    │   唯一接触平台 API 的一层
│          PlatformWin.cpp / PlatformX11.cpp│
│          PlatformMac.mm                   │
└───────────────────────────────────────────┘
```

**关键约束**：`core` 和 `ui` 里不允许出现 `windows.h` / `X11` / `Cocoa` 的任何符号。平台差异只通过
`ac::pl::` 命名空间下的函数暴露，换平台只需要替换 `platform/` 下的一个 `.cpp`。

## 平台接口一览（`src/platform/Platform.h`）

| 分组 | 接口 | Win32 实现 | X11 实现 | macOS 实现 |
| --- | --- | --- | --- | --- |
| 生命周期 | `init / shutdown / backendName / virtualScreen` | `GetSystemMetrics(SM_*VIRTUALSCREEN)` | `XOpenDisplay` + `DisplayWidth/Height` | `CGGetActiveDisplayList` |
| 输入 | `moveTo / mouseDown / mouseUp / click / wheel / key / keyTap` | `SendInput`（绝对坐标） | `XTestFakeMotionEvent` / `XTestFakeButtonEvent` / `XTestFakeKeyEvent` | `CGEventPost(kCGHIDEventTap)`、`CGWarpMouseCursorPosition` |
| 截图 | `grabScreen / grabWindow / windowRect` | `BitBlt` + `PrintWindow(PW_RENDERFULLCONTENT)` | `XGetImage` + `XCompositeNameWindowPixmap` | `CGWindowListCreateImage` |
| 窗口 | `windows / findWindow / activateWindow / windowExists` | `EnumWindows` + `SetForegroundWindow`（Alt 绕行 + TOPMOST 闪现） | `_NET_CLIENT_LIST` + `_NET_ACTIVE_WINDOW` + `XRaiseWindow` | `CGWindowListCopyWindowInfo` + `NSRunningApplication` + AX `kAXRaiseAction` |
| 热键 | `startHotkeys / setHotkey / stopHotkeys` | `RegisterHotKey` + 独立消息线程（`WM_APP+1` 重新注册） | 独立 Display + `XGrabKey`（含 NumLock/CapsLock 变体）+ 8 ms 轮询 | Carbon `RegisterEventHotKey` |
| 录制钩子 | `installHook / removeHook / hookActive` | `WH_MOUSE_LL` + `WH_KEYBOARD_LL`（过滤 `LL*HF_INJECTED` 与自身窗口） | `XRecord`（独立 data 连接线程，阻塞 `XRecordEnableContext`） | `CGEventTap`（`kCGSessionEventTap`，注入事件打 `SourceUserData` 标记） |

## 线程模型

- UI 在主线程；每个任务（`MouseTask` / `TargetTask` / `Player`）各自一条 `std::thread`，通过 `std::atomic<bool>` 停止，`sleepMs()` 以 5 ms 粒度检查停止标志，所以「停止」是即时生效的，不是等一个完整间隔。
- 日志 `Log::instance()` 是单例，任意线程可写（内部 `QMutex`），通过 `line(QString)` 信号回到 UI 线程追加。
- 跨线程给 UI 的通知都用 Qt 信号（自动排队），不直接碰控件。

## 任务与找图

`TargetTask` 把「找图连点」和「监视窗口」合成一个实现，差别只有三个参数：

| | 找图连点 | 监视窗口 |
| --- | --- | --- |
| 画面来源 | `grabScreen(virtualScreen())` | `grabWindow(hwnd)`（必要时按进程/标题重新找窗口） |
| 坐标原点 | (0,0) | 窗口左上角（命中后重新取一次，窗口被移动也不点偏） |
| 点击前动作 | 直接移动+点击 | 先 `activateWindow` + 等 250 ms |

命中判定在 `ImageMatch`：灰度标准差 < 2.0 的模板判为「纯色不可用」；`TM_CCOEFF_NORMED` 全图扫描后按分数排序，用「盒收缩 1/3 后相交即视为同一目标」去重。

## 录制与回放

- `Recorder` 装上平台钩子，把事件转成 `RecEvent{kind,t,x,y,btn,steps,vk,ext}`，时间戳相对录制起点。
- 脚本落盘为 `scripts/<名字>.json`：

```json
{"app":"auto-clicker","version":1,"name":"脚本_1116_1130","created":"2026-11-16 11:30:12",
 "screen":[1920,1080],
 "events":[[3,0,10,20],[1,120,10,20,0],[2,160,10,20,0],[6,300,0x20,0,0]]}
```

事件类型：`1=按下 2=抬起 3=移动 4=滚轮 5=键按下 6=键抬起`。

- `Player`：原速按时间轴对齐（`QElapsedTimer` + 2 ms 轮询），固定间隔对「按下类」事件统一等 N ms；循环到末尾时若还有按键处于按下状态会补一个抬起，避免鼠标卡在按下状态。

## 测试

- `ac_selftest`：纯逻辑，不需要物理输入。覆盖键名映射、配置回环、找图（含纯色拒绝）、脚本读写、任务启停。
- `ac_e2e`：X11 下真注入。启动靶子窗口 → 截窗 → 在同一张截图里找靶心 → 注入点击验证落点 → 挂 XRecord 钩子、由**子进程**注入（避免被自身「注入抑制」过滤）验证录制 → 用录下来的事件回放，验证动作真的又打了一次。
